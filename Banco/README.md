##  Sistema Bancário

Simulador bancário desenvolvido em Python, com operações básicas de gerenciamento de saldo.

---

### Funcionalidades

- Consulta de saldo
- Depósito
- Saque
- Validação de valores
- Verificação de saldo insuficiente
- Menu interativo

---

### Tecnologias

- Python
- Estruturas condicionais
- `match/case`
- Laços de repetição
- Funções
- Entrada e saída de dados
