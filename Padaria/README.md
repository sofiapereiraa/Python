#  Sistema de Padaria

Sistema desenvolvido para simular o atendimento de uma padaria, permitindo consultar o cardápio e realizar compras pelo terminal.

### Funcionalidades

- Visualização do cardápio
- Seleção de produtos
- Definição da quantidade
- Cálculo do valor total da compra
- Menu interativo
- Validação das opções do menu

## Como executar

Execute o arquivo pelo terminal utilizando o Python:

```bash
python padaria.py
