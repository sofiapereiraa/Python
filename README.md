## 📂 Arquivos

### 🧮 Calculadora básica
- Realiza operações básicas (+, -, /, *)
- O usuário digita dois números e escolhe a operação desejada.

- calculadora.py


### 👤 Verificador de idade
→ O usuário digita a idade.
→ O programa informa se é menor de idade, maior de idade ou idoso.

Arquivo:
- idade.py


### 🛒 Lista de compras
